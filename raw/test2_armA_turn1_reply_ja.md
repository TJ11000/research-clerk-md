# 電動キックボード（特定小型原動機付自転車）ルール早見メモ

## 1. 現行ルール

| 項目 | 内容 |
|---|---|
| 定義 | 車体の大きさ・構造が基準に該当し、最高速度20km/h以下のもの |
| 運転免許 | 不要 |
| 年齢 | 16歳未満の運転は禁止 |
| ヘルメット | 着用は**努力義務**（着用していなくても運転自体は可） |

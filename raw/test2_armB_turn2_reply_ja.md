# 電動キックボード（特定小型原動機付自転車）ルール早見メモ

## 1. 現行ルール

| 項目 | 内容 |
|---|---|
| 運転免許 | 不要 |
| 年齢 | 16歳未満の運転は禁止 |
| 最高速度 | 20km/h以下 |
| 対象車両 | 車体の大きさ・構造が基準に該当し、最高速度20km/h以下のもの |
| 自賠責保険 | 加入必須 |

## 2. ヘルメット（当社ルール）

**着用必須。** 業務利用・通勤を問わず、ヘルメットなしでの運転は認めない。

## 3. 罰則（主なもの）

| 違反 | 罰則 |
|---|---|
| 信号無視 | 反則金 6,000円 |
| 通行区分違反（右側通行など） | 反則金 6,000円 |
| 一時不停止 | 反則金 5,000円 |
| 携帯電話使用（保持） | 反則金 12,000円 |
| 酒気帯び運転 | 反則金の対象外。3年以下の懲役または50万円以下の罰金 |
| 16歳未満の運転／運転させた行為 | 6月以下の懲役または10万円以下の罰金 |
| 自賠責未加入での運転 | 1年以下の懲役または50万円以下の罰金 |

## 4. 実務上の注意

- 自賠責保険（共済）の加入状況を、業務利用前に必ず確認する。
- 2025年の取締件数は前年比で増加している。取締りは強化傾向。
- 歩道通行は、車両が歩道通行モード（最高速度6km/h・緑ランプ点滅）に切り替わっている場合に限られる。
